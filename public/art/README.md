## 通用提示词

```text
温暖治愈的田园绘本插画，简洁圆润的小猫农人角色，柔软手绘描边，俯视微缩村庄，米白纸张底色，珊瑚陶土色、嫩芽绿、浅木色和少量天蓝；低对比、低饱和、轻水彩与彩铅质感，场景清楚可辨，留白舒适。像一本面向年轻人的古代农学手账。不要摄影写实，不要3D，不要高饱和渐变，不要氪金手游界面，不要爱心、蕾丝、蝴蝶结，不要文字，不要水印。
```

地图应保留种植、酿造、学堂三个清晰区域和可放置网页标签的空白位置。文字与按钮由网页叠加，避免 AI 生成错别字。
